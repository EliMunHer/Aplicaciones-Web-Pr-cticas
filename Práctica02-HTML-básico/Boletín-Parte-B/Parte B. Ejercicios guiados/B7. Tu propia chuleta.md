# *B7. Tu propia chuleta*

Aplicaciones Web | 2 SMR (vesprada) | Eliseo Muñoz Hernández

```html
<!DOCTYPE html>
<html>
<head>
    <title>B7 - Mi chuleta HTML</title>
</head>
<body>

    <h1>Mi chuleta de HTML</h1>

    <h2>Imagenes</h2>

    <p>Para insertar imagenes utilizamos la etiqueta img.</p>

    <p>El atributo src indica donde esta la imagen.</p>

    <p>El atributo alt muestra un texto alternativo.</p>

    <h2>Enlaces</h2>

    <p>Para crear enlaces utilizamos la etiqueta a.</p>

    <p>El atributo href indica el destino del enlace.</p>

    <p>El atributo target="_blank" abre el enlace en otra pestaña.</p>

    <h2>Formatos de imagen</h2>

    <p>JPG: fotografias.</p>
    <p>PNG: imagenes con transparencia.</p>
    <p>SVG: imagenes vectoriales.</p>
    <p>GIF: imagenes animadas.</p>
    <p>ICO: iconos de paginas web.</p>

    <h2>CSS y estilos</h2>

    <p>El atributo style permite modificar el aspecto de los elementos.</p>

    <p>Podemos cambiar colores, tamaños, bordes y posiciones.</p>

    <h2>Enlaces al PDF</h2>

    <p>
        <a href="chuleta.pdf">
            Abrir chuleta en esta ventana
        </a>
    </p>

    <p>
        <a href="chuleta.pdf" target="_blank">
            Abrir chuleta en otra pestaña
        </a>
    </p>

    <p>
        <a href="https://www.w3schools.com/html/">
            Tutorial de HTML
        </a>
    </p>

</body>
```
