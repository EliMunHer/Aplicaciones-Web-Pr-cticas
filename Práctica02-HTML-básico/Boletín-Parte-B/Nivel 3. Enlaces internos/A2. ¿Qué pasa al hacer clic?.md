### A2. ¿Qué pasa al hacer clic?

#### Caso A
```html
<a href="#precios">Ver precios</a>
<h2 id="precios">Precios</h2>
```
* **Resultado:** **Funciona correctamente.** El navegador se desplaza dentro de la misma página hasta el encabezado `<h2>Precios</h2>`, ya que el ancla (`#precios`) y el `id` coinciden exactamente.

---

#### Caso B
```html
<a href="#Precios">Ver precios</a>
<h2 id="precios">Precios</h2>
```
* **Resultado:** **No salta al elemento.** Los identificadores (`id`) distinguen entre mayúsculas y minúsculas (*case-sensitive*), por lo que `#Precios` no encuentra `id="precios"`. La URL del navegador añadirá `#Precios` al final, pero la vista no se desplazará hacia la sección.

---

#### Caso C
```html
<a href="guia.html#instalacion">Ir a la instalación</a>
```
* **Resultado:** **Abre otra página en una sección concreta.** El navegador carga el archivo `guia.html` y salta directamente al elemento que tenga `id="instalacion"` dentro de ese documento (si dicho `id` no existe en `guia.html`, simplemente la abrirá desde el principio).
