# *A5. Caza los errores de la galería*

Aplicaciones Web | 2 SMR (vesprada) | Eliseo Muñoz Hernández

```html
<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>Mi galería</title>
</head>
<body>
<h1>Mi viaje de fin de curso</h1>
<img>src="playa.jpg" alt="Playa al atardecer"</img>
<img src="monte.jpg" style="width=300px; height=200px;">
<a href=https://www.wikipedia.org target="_blank">Más información sobre el destino
</body>
</html>
```

1. Primera `<img>` mal escrita: Los atributos van dentro de `<img ...>` y esta etiqueta no lleva cierre `</img>`.
2. Error en style: Se usan dos puntos (:), no igual (width:300px; height:200px;).
3. Falta alt: La segunda imagen necesita su descripción alternativa (alt="...").
4. Comillas en href: La dirección web del enlace debe ir entre comillas (href="https://...").
5. Enlace sin cerrar: Falta poner `</a>` al final del texto del enlace.
