# A5. Comentarios y anidación

Aplicaciones Web | 2 SMR (vesprada) | Eliseo Muñoz Hernández

**Un aviso de ciberseguridad tiene dos errores.**

`<!- Revisar el texto antes de publicar ->`

`<p>Tu contraseña debe tener <strong><em>al menos 12 caracteres</strong></em>.</p>`

1. Primer error:
**Comentario HTML mal escrito:** falta un guion (-) al principio. Se debe escribir <!-- en lugar de <!-.

2. Segundo error:
**Etiquetas mal anidadas:** `<strong>` se cierra antes que `<em>`, pero debe respetarse el orden inverso al de apertura.

**Código corregido:**

`<!-- Revisar el texto antes de publicar -->`

`<p>Tu contraseña debe tener <strong><em>al menos 12 caracteres</em></strong>.</p>`
