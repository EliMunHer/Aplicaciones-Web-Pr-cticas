# A4. Estilos rotos

Aplicaciones Web | 2 SMR (vesprada) | Eliseo Muñoz Hernández

**El community manager de un streamer ha escrito estas líneas para el banner de su canal. Ninguna se ve como debería. Explica qué falla en cada una y corrígela.**

`<h1 style="color:red font-size:40px;">Directo esta noche</h1>`

`<p style="text-align=center;">Estreno de temporada</p>`

`<p style="background-color:yellow;">Sorteo de una tarjeta gráfica<p>`

1. Primer código:
- Falta un punto y coma (;) entre color:red y font-size:40px.
- Corrección:

`<h1 style="color:red; font-size:40px;">Directo esta noche</h1>`

2. Segundo código:
- Se utiliza = en lugar de : para asignar el valor a text-align.
- Corrección:

`<p style="text-align:center;">Estreno de temporada</p>`

3. Tercer código:
- La etiqueta `<p>` no está cerrada correctamente. Se ha escrito otra etiqueta de apertura (`<p>`) en lugar de la etiqueta de cierre (`</p>`).
- Corrección:

`<p style="background-color:yellow;">Sorteo de una tarjeta gráfica</p>`
