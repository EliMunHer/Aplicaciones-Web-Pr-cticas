# A3. Caza los errores

Aplicaciones Web | 2 SMR (vesprada) | Eliseo Muñoz Hernández

`<html>`

`<head>`

`<title>Mi tienda de gadgets`

`</head>`

`<body>`

`<h1>Ofertas de otoño</h2>`

`<p>Auriculares con <b>cancelación de ruido</p></b>`

`</body>`

`</html>`

1. Falta cerrar la etiqueta `<title>`: se abre, pero no aparece `</title>`.

1. Falta el signo `>` en el cierre de `<title>`: el título queda incompleto.

1. El encabezado `<h1>` está mal cerrado: se abre con `<h1>`, pero se cierra con `</h2>`.

1. Las etiquetas `<b>` y `<p>` están mal anidadas: se cierra `<p>` antes que `<b>`.

1. El orden de cierre de las etiquetas es incorrecto: las etiquetas deben cerrarse en orden inverso al que se abren
