# A2. Relaciona etiqueta y efecto

Aplicaciones Web | 2 SMR (vesprada) | Eliseo Muñoz Hernández

| Etiqueta | Relación | Efecto |
| :--- | :--- | :--- |
| 1. `<mark>` | B | Texto remarcado, como con un fosforito |
| 2. `<del>` | A | Texto tachado (precio antiguo de una oferta) |
| 3. `<sub>` | E | Texto en subíndice (como en H₂O) |
| 4. `<sup>` | F | Texto en superíndice (como en m²) |
| 5. `<small>` | D | Texto más pequeño que el normal |
| 6. `<em>` | C | Texto enfatizado (se ve como cursiva) |
| 7. `<ins>` | G | Texto insertado (se ve subrayado) |
